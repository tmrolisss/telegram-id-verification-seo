# Telegram 批量 CSV / TXT 数据清洗格式

## 支持格式

每行一组姓名和证件号码，支持空格、逗号、顿号、竖线分隔：

```text
张三 11010519491231002X
李四,320106198803150012
王五|440305199207082345
```

打码数据也可以混合上传：

```text
张* 110105********002X
```

系统会自动分类、去重、跳过空行和 `#` 开头的注释行，并返回 CSV 结果。

## 推荐流程

1. 整理 UTF-8 编码的 txt 或 csv 文件。
2. 在 Telegram 打开 [@xinxi_heyan_bot](https://t.me/xinxi_heyan_bot?start=src_github_batch)。
3. 发送 `/start`，完成人机验证。
4. 直接发送文件。
5. 下载返回的 CSV 文件。
